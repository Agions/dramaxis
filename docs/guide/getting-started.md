# 快速上手指南 (Getting Started)

欢迎使用 **Dramaxis (剧枢)** —— 工业级短剧 AI 叙事理解与视频工程自动化生产桌面引擎。本文档将指引您在 3 分钟内完成底层环境校验、凭证配置与首部影视剧解说工程的全流程生产。

---

## 1. 运行环境与硬件要求

Dramaxis 依托 Tauri 2.0 与 Rust 原生运行时构建，对计算资源占用极低，但在音视频硬解码与深度处理场景依赖宿主环境的媒体工具链：

| 平台环境 | 最低配置要求 | 推荐生产配置 | 硬件加速支持 |
| :--- | :--- | :--- | :--- |
| **macOS** | macOS 12 (Monterey)+ (Intel / Apple Silicon) | macOS 14+ (Apple Silicon M-Series) | VideoToolbox (H.264 / HEVC 硬解) |
| **Windows** | Windows 10 64-bit (1909+) | Windows 11 64-bit | NVIDIA NVENC / Intel QSV / AMD AMF |
| **内存 (RAM)** | 8 GB 物理内存 | 16 GB ~ 32 GB 统一内存 | 支持高并发批处理内存池 |
| **媒体引擎** | 系统安装 `ffmpeg` 与 `ffprobe` (4.4+) | FFmpeg 6.0+ (启用 libmp3lame 与 hwaccel) | 毫秒级探测与静音端点扫描 (VAD) |

> [!TIP]
> 引擎在冷启动时将通过 `dramaxis-detect::Ffmpeg::discover()` 自动检索系统 `PATH`。若使用独立绿色版或便携版 FFmpeg，可在客户端「设置 ➔ 环境与依赖」中手动绑定二进制绝对路径。

## 2. 安全凭证与大模型矩阵配置

Dramaxis 采用操作系统级安全保险库存储鉴权凭证（macOS Keychain / Windows Credential Manager），内存运行时隔离脱敏，绝不向 Webview 前端暴露明文密钥。

1. 打开应用左下角 **⚙️ 设置 (Settings)** ➔ **模型与服务 (Providers & Credentials)**。
2. 配置 **大语言模型 (LLM Providers)**：
   - 填入对应服务商的 API Key（如通义千问 Qwen、DeepSeek V3/R1、OpenAI GPT-4o、Claude 3.7 Sonnet、Google Gemini 2.5 等）。
   - 如使用私有网关或中转集群，勾选「自定义 Base URL」并输入兼容端点。
   - 点击 **「⚡ 测试连通性」** 验证网络握手与端点可用性。
3. 配置 **语音合成服务 (TTS Providers)**：
   - 支持免密钥开箱即用的高保真 Edge-TTS（默认预设 `zh-CN-YunxiNeural` 剧情解说音色）。
   - 支持商用级 OpenAI TTS、MiniMax 以及本地离线部署的 GPT-SoVITS 零样本音色克隆。

## 3. 全链路端到端创作流程

```mermaid
graph LR
    A["1. 素材摄取与编码探测"] --> B["2. 生产策略与工作流设定"]
    B --> C["3. 6-Agent 状态图协同生产"]
    C --> D["4. 5轨时间轴声画监看与微调"]
    D --> E["5. 剪映草稿直出 / 母带交付"]
```

### 第一步：素材摄取与多模态探针解析

1. 在客户端主界面点击 **「新建项目 (New Project)」** 或直接将待处理的影视剧切片拖入素材监看区。
2. `dramaxis-intake` 与 `dramaxis-detect` 引擎将在毫秒级内完成媒体流探测：
   - **元数据抽检**：精确探测封装格式、视频编解码（如 H.264 / AV1）、色彩空间、真实帧率与音轨声道数。
   - **场景突变打点**：利用 FFmpeg 场景采样过滤器捕获硬切边界，为后续镜头分镜划分提供骨架基准。

### 第二步：选择生产策略 (Production Strategy)

依据创作业务目标选择对应的流水线策略：

- **单片精剪 (Single)**：单镜头或单一影视长片生成完整结构化深度独白解说。
- **多片段拼接 (Concat)**：多镜头序列按时间序与故事冲突脉络合并生成解说。
- **批量并发 (Batch)**：为大批量素材切片并发启动无锁化隔离的智能体批处理。
- **连载剧集 (Series)**：保持跨集长程上下文、人物关系图谱与叙事风格一致性。

### 第三步：启动 6-Agent 状态图协同创作

切换至 **「🎬 编导致作工坊 (Production Studio)」**，点击 **「🚀 启动全流程生产」**。底层基于 `StateGraph + Blackboard` 的 6 大智能体将自动流转：

1. **`Director` (总控导演智能体)**：拆解参考爆款样本风格，生成结构化大纲与镜头字数预算。
2. **`VisualCritic` (视觉分析智能体)**：识别画面冲突度、运动速率并输出多模态视觉特征描述。
3. **`Screenwriter` (金牌编剧智能体)**：应用黄金 3 秒 Hook 公式，生成第一人称高冲突独白脚本。
4. **`VoiceArtist` (声乐调音智能体)**：匹配角色情绪声线，注入 SSML 停顿并合成 48kHz 配音。
5. **`SoundEngineer` (混音剪辑智能体)**：执行原声与配音真实 VAD 断句，依托 `DualDrivenAligner` 自动完成 5 轨毫秒级磁吸与 BGM 旁链闪避。
6. **`QualityReviewer` (终审守门智能体)**：执行 4-Gate 客观质检（Hook强度、声画公差、镜头节奏、平台合规词扫描），签发交付评定。

### 第四步：5 轨时间轴声画监看与微调

在内建的多轨非编监看台上，您可以实时查看：
- **V1 视频主轨** 与场景切点指示标。
- **A1 独白配音轨**、**A2 环境音效轨** 与 **A3 背景配乐轨**。
- **T1 动态字幕轨**：毫秒级字级/词级时间戳，琥珀金等爆款花字预设。
- 体验独白发声时 BGM 自动平滑衰减至 `-18dB` 的智能避让效果。

### 第五步：剪映 PC 原生草稿秒出与平台母带交付

在导出面板中可自由选择目标交付形态：
- **剪映 PC 原生草稿 (.draft)**：秒级生成标准 CapCut / JianYing 工程目录结构，0 转码等待，直接唤醒剪映进行二次工业级包装。
- **多平台定制母带**：一键导出 9:16（抖音/快手）、16:9（B站/YouTube）等标准画幅成片，配合 EBU R128 响度标准化与平台安全区微调。
