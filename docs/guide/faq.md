# 常见问题排查与运维指南 (FAQ)

本文档整理了创作者与工程研发人员在部署、运行及扩展 **Dramaxis (剧枢)** 过程中常见的环境适配、大模型调用、音视频编解码与工程导出问题及官方解决方案。

---

## 1. 基础设施与媒体引擎

### Q1: 应用启动时提示「未检测到系统 FFmpeg 依赖」如何处理？

- **原因分析**：Dramaxis 底层 `dramaxis-detect` 引擎在启动时调用 `which("ffmpeg")` 与 `which("ffprobe")` 检索系统环境变量。若未将可执行文件加入系统 `PATH`，将无法启动硬切检测与 VAD 静音端点探测。
- **排查与解决**：
  - **macOS**：通过 Homebrew 一键安装：
    ```bash
    brew install ffmpeg
    ```
  - **Windows**：通过 WinGet 包管理器或下载官方构建包：
    ```powershell
    winget install Gyan.FFmpeg
    ```
  - **路径自定义**：亦可进入客户端 **「⚙️ 设置 ➔ 环境配置」**，在「FFmpeg 路径」输入框中直接浏览并选定二进制文件（如 `/opt/homebrew/bin/ffmpeg` 或 `C:\ffmpeg\bin\ffmpeg.exe`）。

### Q2: 如何验证 macOS 或 Windows 下的硬件加速 (GPU) 是否正常生效？

- **排查步骤**：
  进入设置面板中的「硬件编解码探针」，系统将自动执行探测并展示可用加速器：
  - macOS 设备显示 `VideoToolbox (Apple Silicon H.264/HEVC/ProRes)`。
  - Windows 设备显示 `NVIDIA NVENC` / `Intel QuickSync (QSV)` / `AMD AMF`。
  - 若硬件加速未启用，系统会自动平滑降级至高性能多线程软解（`libx264`），确保业务流程 100% 连贯可用。

## 2. 大模型网关与智能体编排

### Q3: LLM 大模型请求频繁超时或返回 `HTTP 401 / 429` 错误？

- **排查步骤**：
  1. **凭证校验**：进入「设置 ➔ 模型与凭证」，确认填写的 API Key 完整无空格，并点击右侧 **「⚡ 测试连通性」** 发起轻量健康检查。
  2. **中转 Base URL**：若采用企业私有网关或中转代理，请确认填写的是完整的 OpenAI 兼容协议前缀（例如：`https://api.yourproxy.com/v1` 或兼容的 chat completions 完整父路径）。
  3. **并发与速率限制 (429)**：Dramaxis 的多智能体 DAG 引擎（如 `Screenwriter` 与 `VisualCritic`）内置了指数退避与并发 Semaphore（默认最大并发为 2），若 API 服务商 QPS 配额偏低，可在设置中调低智能体并发上限。

### Q4: 编剧生成的台词被质检守门员（Gate 4）拦截打回怎么办？

- **原因分析**：`QualityReviewerAgent` 内置了平台敏感词与合规扫描器。若剧本文案命中违禁极限词（如“国家级”、“第一”、“最高级”、“绝对包赚”）或总时长超出平台推荐阈值，综合评分将被拉低并触发 HITL 人工介入断点。
- **解决方案**：
  - 在断点弹窗中，创作者可输入针对性指导提示词（如“去除绝对化字眼，改用更具悬疑感的口吻”），点击「靶向重修」；
  - 智能体系统将仅针对编剧节点执行局部无损回退与重新生成，无需重跑整条流水线。

## 3. 音频合成与声画对齐

### Q5: 为什么独白发声时背景音乐 (BGM) 仍然过响听不清台词？

- **原理与校准**：Dramaxis 采用基于侧链压缩的智能音频避让算法 (Audio Ducking)。
- **调节建议**：
  - 在制作工坊右侧面板中，确认已勾选 **「BGM 智能自动避让」**。
  - 将避让衰减深度调节至 `-12dB` ~ `-18dB`，此时当 A1 轨检测到独白发声时，A3 配乐轨将以 120ms 的平滑起音时间自动降噪压暗；当台词停顿时平缓恢复原有电平。

### Q6: 为什么个别素材的 VAD 语音断句区间识别不准确？

- **排查建议**：
  - `dramaxis-subtitle::vad` 默认静音阈值为 `-40.0dB`，最小有效语音段为 `200ms`。
  - 若素材背景噪音极高（如嘈杂街景或低信噪比录像），可进入高级音频设置，将静音检测阈值调整至 `-35.0dB`，以更精准地过滤连续背景噪底。

## 4. 剪映工程与平台母带交付

### Q7: 导出的剪映草稿打开后弹出「素材文件丢失」提示？

- **根因说明**：剪映工程草稿 `.draft` 采用的是轻量化媒体绝对路径索引机制。若导出草稿后原视频被移至回收站、外部 U 盘被拔出或文件夹重命名，剪映将无法定位素材源。
- **解决方式**：
  - 导出前建议将所有待剪辑资产统一集中在稳定的本地工作目录中；
  - 若已丢失，可在剪映弹窗中点击「重新链接」，定位至素材当前所在目录即可瞬间恢复。
