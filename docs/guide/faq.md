# 常见问题与排查指南 (FAQ)

本文档汇集了开发者与创作者在配置和使用 splicr 过程中最常遇到的问题及解决方案。

---

## 1. 环境与依赖问题

### Q1: 提示「未检测到系统 FFmpeg」如何解决？

- **原因**：系统环境变量 `PATH` 中未包含 `ffmpeg` 与 `ffprobe`。
- **排查与解决**：
  - **macOS**：通过 Homebrew 安装：`brew install ffmpeg`
  - **Windows**：通过 winget 或官网下载：`winget install Gyan.FFmpeg`
  - 亦可在 splicr **「设置 ➔ 环境配置」** 中直接手动浏览并选择 `ffmpeg` 所在二进制文件路径。

### Q2: macOS 提示「应用已损坏，无法打开」或拦截未签名二进制？

- **原因**：这可能表示应用未签名/未公证，也可能是下载损坏；仅凭提示无法安全地区分原因。
- **建议**：不要移除 quarantine 隔离标记或关闭 Gatekeeper。请仅从官方发布页下载，并在维护者提供时校验签名或哈希。若仍被拦截，请停止运行并联系维护者获取可验证的发布包；不要通过 `sudo xattr` 绕过系统保护。

## 2. 大模型与配音接口问题

### Q3: 模型请求超时或报错 `401 Unauthorized`？

- **排查步骤**：
  1. 打开 **「设置 ➔ 模型与凭证」**，检查对应厂商（如 OpenAI、DeepSeek、阿里云等）的 API Key 是否输入完整且无前后空格。
  2. 如果使用第三方代理服务或中转 Base URL，请确认已勾选「自定义 Base URL」并填入完整代理地址（如 `https://api.openai.com/v1`）。
  3. 点击输入框旁的 **「⚡ 测试连通性」** 按钮，系统会发起轻量 ping 请求并返回详细错误状态码。

### Q4: Edge TTS 合成较慢或断流？

- **原因**：部分网络环境下微软公共 TTS 节点可能存在波动或防火墙限制。
- **建议**：
  - 在「设置」中切换备用 TTS 供应商（如 OpenAI TTS 或本地部署的 GPT-SoVITS）。
  - 在「网络配置」中配置代理出口。

## 3. 视频生成与时间轴问题

### Q5: 为什么 BGM 背景音乐人声被覆盖听不清？

- **解决方案**：splicr 内置了智能音频避让 (Audio Ducking) 算法。
  - 请确认是否启用了「BGM 自动避让」功能。
  - 如果人声依然偏小，可以在时间轴将解说音轨的音量滑块调高至 `+2.0dB` 或 `+3.0dB`，并将避让衰减值设置到 `-8dB` 以下。

### Q6: 导出的剪映草稿打开后提示素材丢失？

- **原因**：原始导入的视频素材文件被移动、重命名或删除了。
- **解决**：剪映草稿内部保存的是本地媒体的绝对文件路径。请将原素材放回原路径，或在剪映弹出的关联提示中重新指定素材文件。
