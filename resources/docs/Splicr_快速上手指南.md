## 1. 系统简介与核心特性

**Splicr** 是一套专为影视解说、短视频二创与纪录片解说量身打造的**桌面级工业化多智能体创作引擎**。不同于传统的线性非编剪辑软件，Splicr 引入了“多智能体协同流水线”工作范式：

- **6 大智能体协同**：编剧分析师（Screenwriter）、音频调度师（Voice Director）、调色质检员（Colorist）等角色全流程协同。
- **7 步标准解说流水线**：素材摄入 ➔ 场景切片 ➔ AI 文案构思 ➔ 语音合成 ➔ 音频分段 ➔ 画面自动匹配 ➔ 剪映草稿一键导出。
- **Rust Native 编解码与无缝渲染**：依托原生底层管道与 FFmpeg 硬件加速（VideoToolbox / NVENC / QSV），实现低延迟、低内存占用的高效处理。
- **全格式字幕引擎**：内置统一的 `splicr-subtitle` 核心，支持标准 SRT、VTT 以及专业卡拉OK级 ASS 逐字动态高亮字幕。

## 2. 运行环境与依赖配置

### 2.1 操作系统要求

- **macOS**：macOS 12 (Monterey) 或更高版本（原生适配 Apple Silicon M 系列与 Intel 芯片）。
- **Windows**：Windows 10 / 11 64 位版本。
- **Linux**：Ubuntu 22.04+ / Debian 12+ / Arch Linux。

### 2.2 前置外部依赖：FFmpeg

Splicr 的底层智能探针、场景切片识别（Scene Detection）与音视频合成重度依赖 **FFmpeg 5.0+**。

#### 安装方法：

- **macOS (Homebrew)**:
  ```bash
  brew install ffmpeg
  ```
- **Windows (Scoop / Winget)**:
  ```powershell
  winget install Gyan.FFmpeg
  # 或
  scoop install ffmpeg
  ```
- **验证安装**:
  打开终端或 PowerShell 执行：
  ```bash
  ffmpeg -version
  ```
  若能正确输出版本信息，即表示系统环境已就绪。Splicr 启动时会自动探测系统 `PATH` 中的 FFmpeg 并初始化硬件加速模块。

## 3. 五分钟快速上手实操

### 第一步：新建项目与批量导入素材

1. 启动 Splicr 客户端，在主欢迎面板点击 **「新建项目 (New Project)」** 或按键盘快捷键 `⌘N` (Windows 下为 `Ctrl+N`)。
2. 进入工作台后，在顶部导航栏点击 **「批量导入素材」**，将电影、电视剧或录制视频文件（支持 `.mp4`, `.mov`, `.mkv`, `.flv` 等）直接拖入窗口。
3. 引擎将自动对素材进行音视频格式探测（分辨率、帧率、时长与音轨数量）。

### 第二步：智能场景切片 (Scene Detection)

1. 在素材库列表中选中待处理素材，点击 **「智能切片」**。
2. 底层 Rust 原生引擎将调用 FFmpeg 场景识别探针，在数秒内自动提取分镜镜头切换点（Cuts Timeline）。
3. 创作者可在时间轴上直观预览每个镜头的起始时间、镜头时长与缩略图切片。

### 第三步：生成解说文案与分镜对齐

1. 进入 **「智能生产工作台 (Production Studio)」**。
2. 点击右侧的 **「AI 解说文案」** 面板，输入影片类型、解说语气（如“悬疑反转”、“幽默风趣”、“沉浸独白”）或剧情大纲。
3. 点击 **「生成解说文案」**，所配置的 LLM 将自动按镜头节奏将解说文案分割为对应分段（`seg_00`, `seg_01`...）。

### 第四步：试听并生成真人级配音

1. 切换至 **「配音工作室 (Voice Studio)」** 面板。
2. 选择心仪的配音引擎与声线（支持 Edge-TTS 免费声线、MiniMax 48kHz 超高清超拟真声线、OpenAI TTS、GPT-SoVITS 自定义克隆）。
3. 点击 **「试听生成」** 预览效果；满意后点击 **「生成整轨配音」**。

### 第五步：时间轴微调与人机协同 (HITL)

1. 在多轨道时间轴（MultiTrack Timeline）上观察视频画面轨道、解说配音轨与字幕轨道的对齐状态。
2. 引擎在关键步骤提供断点暂停机制（Human-in-the-Loop），创作者可随时介入调整分句文案或微调切片时间点。

### 第六步：一键导出剪映专业草稿

1. 确认无误后，点击工作台右上角的 **「导出剪映草稿」**。
2. Splicr 将自动生成标准的剪映工程结构文件（`draft_content.json` 及素材软链接），并在成功后弹出通知。
3. 打开剪映专业版即可在本地草稿列表中看到刚刚生成的完整解说工程，轨道素材、配音音频、画中画与字幕已全部对齐到位！

## 4. AI 大模型与声音克隆配置

进入应用左侧导航的 **「设置中心 (Settings)」** ➔ **「模型与密钥」** 进行参数持久化配置：

### 4.1 大语言模型 (LLM Providers)

Splicr 完整支持 11 大主流商业与开源大模型：

- **DeepSeek**：推荐 `deepseek-chat`，性价比极高，影视剧情逻辑推理与段子编写能力卓越。
- **OpenAI**：支持 `gpt-4o`、`gpt-4o-mini`，综合文本连贯性与分镜切分极佳。
- **通义千问 (Qwen)**：支持 `qwen-plus`、`qwen-max`，本土化成语、俗语与悬疑叙事极强。
- **智谱 GLM**：支持 `glm-4-flash` / `glm-4`，响应速度极快。
- **月之暗面 (Moonshot)**：支持 `moonshot-v1-auto`，超长影视剧情一次性深度分析。
- **自定义 Base URL**：如果使用中转 API 或本地 Ollama / vLLM 私有化部署，可直接填写自定义接口地址。

### 4.2 语音合成引擎 (TTS Engines)

- **Edge-TTS**：微软原生声线（如 `zh-CN-YunxiNeural`, `zh-CN-YunjianNeural` 等），无需填写 API Key，开箱即用，完全免费。
- **MiniMax (Mimo)**：支持 `speech-02-hd` 与 `male-qn-qingse` 等高质量 48kHz 影院级人声，情感起伏丰富，吐字自然。
- **GPT-SoVITS**：支持本地部署的声音克隆服务，可导入 5 秒真实参考音频（Reference Audio）实现 1:1 声线复刻。

## 5. 剪映草稿一键对接实操

Splicr 导出的剪映草稿完全兼容剪映专业版（CapCut / JianYing Pro）：

1. **草稿路径**：
   - macOS 默认保存在：`~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/`
   - Windows 默认保存在：`C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\`
2. **导出特点**：
   - 视频轨：包含全部切片分镜与关键帧标记；
   - 音频轨：解说主音轨独立成轨，支持后期单独混音加背景音乐；
   - 字幕轨：已嵌入智能断句与时间戳，支持直接在剪映内一键应用花字或样式模板。

## 7. 常见问题排查 (FAQ)

### Q1: 启动时提示“未探测到 FFmpeg”或场景切片失败？

**解答**：请确保系统已安装 FFmpeg 并且其二进制路径已被加入到全局环境变量 `PATH` 中。安装后请完全重启 Splicr 客户端。在终端中输入 `which ffmpeg` (macOS/Linux) 或 `where ffmpeg` (Windows) 检查是否存在有效路径。

### Q2: 生成解说文案时提示“API 调用超时或密钥无效”？

**解答**：

1. 请前往「系统设置」检查对应 Provider 的 API Key 是否包含前后多余空格。
2. 若在国内网络访问海外模型（如 OpenAI / Claude），请在 Base URL 中配置反向代理中转地址，或切换为国内免代理的 DeepSeek / 通义千问。

### Q3: 导出的剪映草稿在剪映中打开提示素材丢失？

**解答**：Splicr 采用绝对路径软链接引用原视频素材。请确保原视频素材在导出后没有被重命名、移动到其他文件夹或删除。

### Q4: 如何在不同颜色主题间切换？

**解答**：点击顶部导航栏右上角的太阳/月亮图标，或按 `⌘K` 输入“切换主题”，即可在【黑金调光室模式 (Cinematic Darkroom)】与【珍珠暖白模式 (Light Mode)】间无缝切换，同时支持跟随系统自动切换。
