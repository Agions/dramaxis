## 1. 系统简介与核心特性

**Dramaxis（剧枢）** 融合了全自动编剧叙事引擎与工业级音视频工程切片技术，打造出专为电影级第一人称解说、深度二创与微短剧剪辑量身定制的**桌面级工业化智能导演系统**。

核心突破特性：

- **6-Agent 协同导演流水线**：总控导演（Director）、画面视觉分析师（VisualCritic）、金牌编剧（Screenwriter）、声乐调音师（VoiceArtist）、混音剪辑师（SoundEngineer）、质量验收员（QualityReviewer）六角色自治协同。
- **5 轨毫秒级对齐时间轴**：原生分离 `Video` (画面轨)、`Voice` (独白人声轨)、`Ambient` (环境音效轨)、`Bgm` (背景音乐轨)、`Subtitle` (智能字幕轨)，实现音画偏差低于 8ms。
- **本地优先沙箱架构 (Local-First Sandbox)**：项目完全离线自治存储于 `~/.dramaxis/projects/<工程ID>/`，素材零拷贝软链入库，保证创作者资产绝对隐私。
- **四道质量闸门自动化严审**：0~3 秒黄金完播率 Hook 审查、音画字幕 VAD 毫秒级同步校验、分镜剪辑节奏呼吸感评分、违规合规性过滤。
- **全格式字幕引擎与剪映原生互通**：内置 SRT / VTT / ASS 专业逐字高亮字幕，一键输出符合剪映专业版协议的 `draft_content.json` 与轨道素材映射。

## 2. 运行环境与依赖配置

### 2.1 操作系统与硬件支持

- **macOS**：macOS 12 (Monterey) 或更高版本（原生适配 Apple Silicon M1~M4 硬件加速芯片与 Intel 架构）。
- **Windows**：Windows 10 / 11 64 位版本（支持 Intel QSV 与 NVIDIA NVENC 硬件编解码加速）。
- **Linux**：Ubuntu 22.04+ / Debian 12+ / Arch Linux（支持 VA-API）。

### 2.2 前置外部依赖：FFmpeg 5.0+

Dramaxis 底层通过高效 Rust 子进程直驱系统级 `ffmpeg` 完成高精度探针分析与画面抽帧：

#### 安装命令：

- **macOS (Homebrew)**:
  ```bash
  brew install ffmpeg
  ```
- **Windows (WinGet)**:
  ```powershell
  winget install Gyan.FFmpeg
  ```
- **验证安装**:
  在终端中运行 `ffmpeg -version`，能输出版本信息即表示环境已就绪。Dramaxis 启动时将自动检测并激活硬件编解码加速。

## 4. 5 轨毫秒级时间轴与本地沙箱

### 4.1 五轨时间轴架构
- **V1 (Video Track)**：镜头切片画面轨，精准标记切点、时长与画面缩略图。
- **A1 (Voice Track)**：第一人称解说独白轨，具备动态波形可视化。
- **A2 (Ambient Track)**：环境音轨，为剧情渲染环境音氛围。
- **A3 (Bgm Track)**：智能配乐轨，独白发声时自动启用 -18% 响度避让 (Ducking)。
- **S1 (Subtitle Track)**：逐字卡拉OK级高亮字幕轨，同步公差严格控制在 50ms 以内。

### 4.2 本地优先沙箱目录规范
每个创作工程在本地享有独立自治沙箱：
```
~/.dramaxis/projects/<工程ID>/
├── project.dramaxis.json      # 核心工程描述符 (元数据/分段/5轨时间轴)
├── media/                     # 素材软链接目录 (绝对路径零拷贝，不冗余占用磁盘)
├── drafts/                    # 导出的剪映/CapCut 专业草稿工程
└── cache/                     # 抽帧切片缩略图、合成音频分段与探针元数据
```

## 5. 五分钟全流程实操指南

### 第一步：新建工程与导入素材
1. 点击主界面 **「新建项目」**（快捷键 `⌘N` / `Ctrl+N`）。
2. 在素材管理器点击 **「批量导入素材」**，拖入待解说的原片（`.mp4`, `.mov`, `.mkv` 等）。
3. 系统将即时创建零拷贝软链并调用硬件探针完成分辨率、帧率与音频通道探测。

### 第二步：一键启动 6-Agent 智能导演流水线
1. 切换至 **「智能生产工作台」**。
2. 设定解说基调与人设（如“反转悬疑”、“毒舌吐槽”、“第一人称沉浸独白”）。
3. 点击 **「启动 6-Agent 智能管线」**（快捷键 `⌘R` / `Ctrl+R`）。六大智能体将全自动并行工作。

### 第三步：人机交互调优 (HITL)
1. 系统在编剧定稿与配音对齐阶段设有断点确认机制。
2. 创作者可在多轨时间轴上直接拖动滑块微调切点，或在文本框直接润色台词。

### 第四步：一键导出剪映专业草稿
1. 确认质检报告全部达标后，点击右上角 **「导出剪映草稿」**（快捷键 `⌘E` / `Ctrl+E`）。
2. 打开剪映电脑版，在草稿列表中直接双击即可打开已经全部装配对齐完毕的 5 轨工程！

## 6. 四道质量闸门 (Quality Gate) 评估标准

质量验收员（QualityReviewerAgent）在管线交付前执行严格评估：

1. **Gate 1 - 0~3 秒黄金开场 Hook 评分 (阈值 ≥ 80.0)**：
   检查首句是否具备强悬念诱导词（如“万万没想到”、“竟然”、“绝密真相”），首句时长是否控制在 3.8s 以内。
2. **Gate 2 - 音画与字幕 VAD 同步公差 (阈值 ≤ 100ms)**：
   通过自研 VAD 算法校验字幕文本起止与独白音频发声时间戳，确保公差控制在 40~50ms 工业级精度。
3. **Gate 3 - 叙事呼吸节奏感 (阈值 ≥ 85.0)**：
   计算分镜切换频率与台词语速的比例，防止单个画面长停滞或切镜过频引发视觉疲劳。
4. **Gate 4 - 违规词与版权安全合规 (阈值 100% 通过)**：
   自动过滤平台敏感词汇与低质违禁内容。

## 9. 常见问题排查 (FAQ)

### Q1: 导入素材后提示探针识别失败？
**答**：请确保系统已正确安装 FFmpeg 并在终端中可执行 `ffmpeg -version`。安装后请完全关闭并重启 Dramaxis 客户端。

### Q2: 编剧文案生成报网络错误？
**答**：请在「设置中心」检查 API Key 与 Base URL 配置。若使用国内直连环境，推荐选用 DeepSeek 或通义千问模型。

### Q3: 剪映打开草稿后出现红字“媒体文件丢失”？
**答**：Dramaxis 为节省磁盘空间采用素材绝对路径软链。导出后请勿重命名、移动或删除原视频源文件。
