1. 系统概述与前置环境配置

Splicr 是一套专为影视解说、短视频二创与纪录片解说量身打造的桌面级工业化多智能体创作引擎。本软件融合了前沿的 LLM 剧情推理、48kHz 高清神经配音、自研卡拉OK动态字幕渲染以及剪映（CapCut）草稿工程一键互通技术。

核心设计理念
Splicr 坚持“单一真相源”、“本地原生高性能”与“创作者断点协同 (HITL)”原则。所有视频切片与音频合成均在本地高效处理，配置文件均落盘至本地系统原生目录，保障创作数据的绝对隐私与资产安全。

1.1 操作系统运行要求

平台名称 最低支持版本 推荐硬件架构
macOS macOS 12 (Monterey) 及以上 Apple Silicon M1/M2/M3/M4 (原生 Metal/VideoToolbox 加速)
Windows Windows 10 / 11 (64-bit) Intel 8代+ / AMD Ryzen 3000+ (支持 NVENC / QSV 硬件加速)
Linux Ubuntu 22.04 LTS / Debian 12 支持 VA-API 硬件解码管道

1.2 必备核心外部依赖：FFmpeg 5.0+

Splicr 的音视频探针分析、智能场景切片提取与多轨流式封装深度依托系统中的 ffmpeg 与 ffprobe 二进制工具。初次使用前请确保已完成安装：

# macOS (推荐通过 Homebrew 一键安装)
brew install ffmpeg

# Windows (推荐通过 WinGet 或 Scoop 安装)
winget install Gyan.FFmpeg

# 验证安装是否成功（在命令行中执行）
ffmpeg -version

2. 核心创作流水线与五步上手实操

Splicr 提供标准化的 7 步多智能体生产流水线，使一部原本需要半天的影视解说作品在 5 分钟内高质量完成初稿编排与剪辑对齐。

1
批量导入原片素材

点击顶部栏「批量导入素材」或按快捷键 Cmd+N。支持同时将整部电影或剧集多集视频文件批量导入素材库，系统自动进行音视频流探针解析。

2
触发 AI 场景切片 (Scene Detection)

在素材列表点击「智能切片」，底层 Rust 原生引擎将通过帧差变化算法自动提取高能分镜切片，生成结构化镜头列表并标定入出点。

3
编剧智能体生成分镜解说文案

进入「智能生产工作台」，在右侧面板设定叙事风格（如“反转悬疑”、“幽默吐槽”），LLM 自动按照镜头节奏分句编写剧情解说词并精准对齐镜头。

4
配音工作室选择声线并合成

选择 Edge-TTS 免费声线或 MiniMax 48kHz 超拟真影视声线，点击「生成整轨配音」。引擎自动生成分段音频并在时间轴上吸附对齐。

5
一键导出剪映专业草稿 (CapCut Draft)

点击右上角「导出剪映草稿」，系统自动在剪映本地草稿目录写入完整的工程文件。打开剪映即可看到排布完毕的视频轨道、解说音频与双语字幕！

2.1 人机协同断点机制 (Human-in-the-Loop)

在多智能体自主执行时，系统设计了优雅的创作者断点机制。当智能体完成阶段性生成（如初版剧本文案或关键帧匹配）后，将暂停等待创作者确认或输入微调反馈（Feedback），确认满意后再继续后续音频与合成步骤，避免盲目全自动带来的失控偏离。

3. 模型密钥配置与高级导出技巧

3.1 大语言模型配置 (LLM Providers)

进入应用设置中心（快捷键 Cmd+, / Ctrl+,）中的「模型与密钥」面板：

推荐模型服务商 推荐默认模型 特色优势与使用场景
DeepSeek deepseek-chat 国内访问零延迟，影视剧情梳理逻辑极强，极具性价比
OpenAI gpt-4o / gpt-4o-mini 文案文学造诣高，镜头切分精准，支持各类海外题材
通义千问 (Qwen) qwen-plus / qwen-max 长文本理解与中文俗语、古装武侠题材解说极其地道
本地私有化 (Ollama) custom (自定义 Base URL) 完全离线内网运行，无需联网密钥，适合高敏感素材处理

3.2 语音合成引擎配置 (TTS Engines)

Splicr 支持免费与商业顶尖音色的灵活搭配：

  • Edge-TTS：无需 API Key，开箱即用，推荐云希（zh-CN-YunxiNeural）与云健（zh-CN-YunjianNeural），适合快速出片。
  • MiniMax (Mimo)：填入 API Key 即可调用 48kHz 影院级超拟真人声（如 male-qn-qingse），换气声、重音语调自然生动。
  • GPT-SoVITS：支持导入 5 秒真实参考音频（Reference Audio），1:1 像素级复刻创作者本人的专属声音声线。

3.3 剪映草稿互通技术规范

跨软件零损耗互通
Splicr 生成的草稿直接符合剪映专业版的 draft_content.json 协议标准。包含独立的视频轨道（切片片段）、解说主音频轨道与字幕轨道。打开剪映客户端后，草稿箱将直接显示工程缩略图，创作者可随时在剪映中套用花字滤镜、特效贴纸或混音推子。

4.2 常见问题速查 (FAQ)

Q1: 启动后场景切片一直无进度或提示错误？

排查方案：请确认电脑已安装 FFmpeg 并且 ffmpeg 位于全局环境变量 PATH 中。安装完成后必须完全退出并重新启动 Splicr，以使系统环境变量生效。

Q2: 导出剪映草稿后，剪映打开提示“媒体文件丢失”？

排查方案：Splicr 为保障处理速度并节省磁盘空间，对原始素材采用路径软链接引用。导出剪映草稿后，请切勿移动、重命名或删除原视频文件。

Q3: 暗色与亮色主题如何切换？

排查方案：点击顶部导航栏右上角的太阳/月亮图标，或按 ⌘K 调出命令面板输入“切换主题”，即可在黑金调光室模式与珍珠暖白模式间瞬时切换，支持跟随系统外观自适应。
