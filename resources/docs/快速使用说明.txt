【前置环境说明】
1. Dramaxis 依赖 FFmpeg (5.0+) 进行底层音视频探针分析、镜头抽帧切片与音频流封装。
   - macOS 用户推荐终端执行: brew install ffmpeg
   - Windows 用户推荐终端执行: winget install Gyan.FFmpeg
   - 请确保在系统终端中输入 "ffmpeg -version" 能正常输出版本信息。
2. Dramaxis 采用纯本地优先架构 (Local-First Sandbox):
   - 所有工程、素材软链与音频缓存均安全保留在本地 ~/.dramaxis/projects/<工程ID>/

【五分钟快速起步】
第一步 [新建工程]:
  启动客户端，点击 "新建项目" (快捷键: Cmd+N / Ctrl+N)。系统将在本地沙箱自动创建专属目录。

第二步 [导入素材]:
  在素材库点击 "批量导入素材"，拖入需要解说的电影、电视剧或纪录片片源 (.mp4/.mov/.mkv)。
  系统建立零拷贝软链，自动执行多模态探针分析。

第三步 [6-Agent 协同导演流水线]:
  进入 "智能生产工作台"，点击 "启动 6-Agent 智能管线" (快捷键: Cmd+R / Ctrl+R):
  - ① 总控导演 (DirectorAgent): 任务拆解与全局调度
  - ② 画面视觉分析师 (VisualCriticAgent): 智能抽帧、转场切点与高能段落提取
  - ③ 金牌编剧 (ScreenwriterAgent): 生成 0~3s 黄金 Hook 与第一人称高能剧情文案
  - ④ 声乐调音师 (VoiceArtistAgent): 生成 48kHz 超拟真配音人声 (Edge-TTS / MiniMax / GPT-SoVITS)
  - ⑤ 混音剪辑师 (SoundEngineerAgent): 自动装载 5 轨毫秒级时间轴 (画面/独白/环境/配乐/字幕)
  - ⑥ 质量验收员 (QualityReviewerAgent): 严格执行四道质量闸门质检 (Hook/同步/节奏/合规)

第四步 [人机协同与微调 (HITL)]:
  流水线支持关键节点断点交互，创作者可随时暂停、在 5 轨时间轴微调对齐或润色文案。

第五步 [一键导出剪映草稿]:
  点击右上角 "导出剪映草稿" (快捷键: Cmd+E / Ctrl+E)。
  打开电脑上的剪映专业版，在草稿箱中即可直接打开已完美对齐的 5 轨工程继续创作！

【核心常用快捷键】
- 空格键 (Space)    : 监视器播放 / 暂停
- Cmd+K / Ctrl+K    : 打开全局命令面板 (Command Palette)
- Cmd+N / Ctrl+N    : 新建创作项目
- Cmd+R / Ctrl+R    : 启动 6-Agent 导演流水线
- Cmd+. / Ctrl+.    : 中断 / 暂停当前流水线
- Cmd+S / Ctrl+S    : 立即保存当前工程
- Cmd+E / Ctrl+E    : 呼出导出面板 (剪映草稿 / 自定义封装)
- Cmd+, / Ctrl+,    : 打开设置中心 (配置 LLM 密钥、TTS 引擎与音色)
- Cmd+/ / Ctrl+/    : 打开帮助与知识库中心

【常见故障快速排除】
1. 场景切片无反应: 检查系统终端是否正确安装并识别 ffmpeg，重启 Dramaxis 客户端。
2. 文案生成报错: 进入 "设置中心" 检查对应 LLM 提供商的 API Key 与 Base URL (国内推荐直连 DeepSeek)。
3. 剪映草稿提示素材缺失: 导出后请勿移动、重命名或删除原始视频源文件。
