【前置环境说明】
1. Splicr 依赖 FFmpeg (5.0+) 进行音视频探针分析、场景切片与格式封装。
   - macOS 用户推荐终端执行: brew install ffmpeg
   - Windows 用户推荐终端执行: winget install Gyan.FFmpeg
   - 请确保在系统终端中输入 "ffmpeg -version" 能正常输出版本信息。

【五分钟快速起步】
第一步 [新建工程]:
  启动客户端，点击 "新建项目" (快捷键: Cmd+N / Ctrl+N)。

第二步 [导入素材]:
  在素材库点击 "批量导入素材"，拖入需要解说的长视频或电视剧片源 (.mp4/.mov/.mkv)。

第三步 [智能切片]:
  在素材列表点击 "智能切片"，引擎将自动调用原生 FFmpeg 算法识别所有镜头切点。

第四步 [AI文案创作]:
  进入 "智能生产工作台"，在右侧 "AI 解说文案" 填写风格提示并生成多镜头解说词。

第五步 [真人配音与微调]:
  在 "配音工作室" 选择音色(免费 Edge-TTS 或 48kHz MiniMax 影院人声)，一键生成配音。
  在下方多轨时间轴上微调画面与音频对齐。

第六步 [导出剪映草稿]:
  点击右上角 "导出剪映草稿"，打开电脑上的剪映专业版，在草稿箱中即可直接继续加工！

【核心常用快捷键】
- 空格键 (Space)    : 监视器播放 / 暂停
- Cmd+K / Ctrl+K    : 打开全局命令面板 (Command Palette)
- Cmd+N / Ctrl+N    : 新建项目
- Cmd+R / Ctrl+R    : 跳转至生产工作台
- Cmd+E / Ctrl+E    : 呼出导出面板
- Cmd+, / Ctrl+,    : 打开设置中心 (配置 LLM 密钥与模型)
- Cmd+/ / Ctrl+/    : 打开帮助中心

【常见故障快速排除】
1. 场景切片无反应: 检查系统是否正确安装 FFmpeg 并重启 Splicr。
2. 文案生成报错: 进入 "设置中心" 检查对应大模型的 API Key 与代理 Base URL。
3. 剪映草稿提示素材缺失: 导出后请勿移动或删除原始视频源文件。

更多详尽图文操作说明，请参阅同目录下的《Splicr_用户使用手册.pdf》或《Splicr_快速上手指南.md》。
